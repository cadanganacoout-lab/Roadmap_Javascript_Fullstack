## ⚡ PHASE 1: Penguatan JavaScript Modern & Asynchronous (Bulan 1)
*Fokus: Menguasai mesin utama JavaScript sebelum menyentuh framework.*

- [ ] **ES6+ Syntax & Features**
  - Menguasai `let` vs `const`.
  - Arrow Functions & shorthand properties.
  - Object & Array Destructuring.
  - Spread & Rest operators (`...`).
- [ ] **Array Methods (Pengganti `foreach` PHP)**
  - `.map()`, `.filter()`, `.reduce()`, `.find()`.
- [ ] **Asynchronous JavaScript (Krusial)**
  - Memahami Event Loop (cara kerja non-blocking JS).
  - Menggunakan `Promise` dan `Async/Await`.
  - Error handling menggunakan `try...catch`.
- [ ] **Fetch API & Axios**
  - Mengambil dan mengirim data ke REST API eksternal.
- [ ] **Git & GitHub Advanced**
  - Memperdalam `git commit`, `git push`, `git branch`, dan manajemen repositori sebagai portofolio.

---

## 🎨 PHASE 2: Modern UI & Fundamental React (Bulan 2-3)
*Fokus: Berpindah dari Bootstrap ke Tailwind CSS, dan memahami konsep Component-driven UI.*

- [ ] **Tailwind CSS**
  - Konsep Utility-first framework.
  - Responsive design dengan prefix Tailwind (`sm:`, `md:`, `lg:`).
  - Kustomisasi file `tailwind.config.js`.
- [ ] **Dasar-Dasar React.js**
  - Memahami JSX (menulis HTML di dalam JavaScript).
  - Komponen & Props (cara memecah UI menjadi potongan kecil yang bisa digunakan ulang).
  - **State Management Dasar:** Menggunakan hooks `useState`.
  - **Side Effects:** Menggunakan hooks `useEffect` untuk mengambil data saat komponen dimuat.
- [ ] **Form Handling & Validasi**
  - Mengontrol input form menggunakan state React.

---

## 🏗️ PHASE 3: Next.js Meta & TypeScript Tech Stack (Bulan 4-5)
*Fokus: Menyatukan Frontend & Backend dalam satu framework modern yang menjadi standar industri.*

- [ ] **TypeScript Dasar**
  - Mengapa industri memakai TypeScript (Type Safety).
  - Tipe data primitif, Interface, dan Types.
  - Implementasi TypeScript pada fungsi dan komponen React.
- [ ] **Next.js (App Router)**
  - **File-based Routing:** Membuat halaman baru dengan struktur folder (`page.tsx`, `layout.tsx`).
  - **Server Components vs Client Components:** Kapan harus menggunakan rendering di server dan kapan di browser.
  - **Data Fetching di Next.js:** Server-side Rendering (SSR) dan Static Site Generation (SSG).
- [ ] **Next.js Server Actions & API Routes**
  - Membuat logika backend langsung di dalam komponen Next.js tanpa Express terpisah (mirip Controller di Laravel).

---

## 🗄️ PHASE 4: Database Modern & Integrasi Backend (Bulan 6-7)
*Fokus: Mengelola data persisten dengan database modern yang cepat skalabilitasnya.*

- [ ] **PostgreSQL & Database Relasional Modern**
  - Migrasi logika dari MySQL ke PostgreSQL.
  - Memahami relasi tabel (One-to-Many, Many-to-Many).
- [ ] **Prisma ORM**
  - Menghubungkan kode JavaScript/TypeScript ke database.
  - Membuat skema database (`schema.prisma`), menjalankan migrasi, dan melakukan operasi CRUD.
- [ ] **Supabase (Backend as a Service)**
  - Menggunakan Supabase sebagai database cloud instan yang berbasis PostgreSQL.
- [ ] **Autentikasi & Keamanan**
  - Implementasi sistem login/register menggunakan **Auth.js (NextAuth)**.
  - Mengamankan rute halaman (Protected Routes).

---

## 🏆 PHASE 5: Capstone Project & Portofolio Kelulusan (Bulan 8)
*Fokus: Membangun satu aplikasi Full Stack utuh berskala besar untuk modal melamar kerja setelah lulus SMK.*

- [ ] **Ide Proyek Rekomendasi:**
  - **Sistem Informasi Internal Tempat PKL:** Aplikasi manajemen inventaris, absensi digital, atau sistem surat-menyurat (jika dii  zinkan tempat PKL).
  - **E-Commerce Platform:** Aplikasi toko online dengan fitur autentikasi, keranjang belanja, integrasi payment gateway (sandbox), dan dashboard admin.
  - **Project Management Web App (Clone Trello/Jira):** Aplikasi manajemen tugas tim menggunakan drag-and-drop.
- [ ] **Deployment & Publikasi**
  - Mendeploy aplikasi Frontend & Backend Next.js ke **Vercel** secara gratis.
  - Menghubungkan database production ke cloud (Supabase/MongoDB Atlas).

## 💡 TIPS BERTAHAN & BERKEMBANG SELAMA PKL

1. **Curi Ilmu dari Kakak Senior:** Amati bagaimana developer di tempat PKL Anda memecahkan masalah kode, membaca error, dan menyusun arsitektur aplikasi (meskipun mereka pakai PHP, logikanya tetap sama).
2. **Cicil 1-2 Jam Sehari:** Jangan belajar sekaligus 8 jam di hari libur. Lebih baik 1 jam setiap sepulang PKL secara konsisten.
3. **Pamerkan Kode Anda:** Setiap kali menyelesaikan modul latihan kecil, langsung *commit* dan *push* ke GitHub. Rekrutmen modern lebih melihat histori kontribusi GitHub Anda daripada nilai rapor sekolah.
