# RoadMap Belajar Full Stack JavaScript

Folder ini berisi materi pembelajaran dan roadmap untuk mengembangkan skill menjadi Full Stack Developer dengan stack modern berbasis JavaScript.

Tujuan folder ini adalah membantu proses belajar secara terstruktur, mulai dari dasar JavaScript, React, Tailwind, Next.js, TypeScript, database, backend, hingga project akhir yang siap dipamerkan sebagai portofolio.

## Fokus pembelajaran
- JavaScript modern dan asynchronous
- React + UI/UX dasar
- Next.js dan TypeScript
- Database modern (PostgreSQL/Supabase)
- Backend dan autentikasi
- Capstone project dan deployment

## File utama
- `roadmap-checklist.md` — daftar roadmap dalam bentuk checklist progress belajar
- `roadmap-explanation.md` — penjelasan detail tiap phase, konsep, dan contoh kode

## Target penggunaan
Folder ini dibuat untuk:
- siswa SMK RPL yang sedang masa PKL atau belajar mandiri
- peserta yang ingin beralih dari PHP/MySQL ke ekosistem JavaScript modern
- siapa pun yang ingin memiliki roadmap belajar yang jelas dan terarah

Semua materi di folder ini disusun agar pembelajaran lebih mudah dikelola per fase dan tidak terasa terlalu berat jika dilakukan secara konsisten.
